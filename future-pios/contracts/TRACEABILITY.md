## Stable IDs

Use one identity system. Example values live in `../demos/stable-ids.example.json`.

Minimum IDs:

- Project ID
- Requirement ID
- Journey ID
- Test ID
- Execution ID
- Evidence ID

Later:

- Defect ID
- Risk ID
- Release ID
- Decision ID
- Knowledge ID
- Incident ID
